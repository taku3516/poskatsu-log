# ポス活ログ

品川区内のポスティング活動を、Googleアカウント単位で記録・同期・分析するモバイル向けPWAです。

## 主な機能

- タイマー入力と手動入力
- 複数配布物・複数担当者・町丁目別内訳
- CSVインポート・エクスポート
- 月間目標、活動履歴、分析ダッシュボード
- OpenStreetMapと町丁目別人口・世帯数
- 配布実績による地図表示切り替え
- 大型マンションの配布可否・確認履歴
- LINE等へのテキスト・PNG画像共有
- オフライン入力
- Googleログインによる同一アカウントの複数端末同期

## ローカル起動

```bash
npm run serve
```

`http://localhost:4173/` を開きます。Firebase未設定時は端末内保存モードで動作します。

## Firebase

Firebaseは利用者が手動設定します。詳細は [Firebase手動設定手順](docs/FIREBASE_SETUP.md) を参照してください。

## 検証

```bash
npm test
```

## データ出典

- 人口・世帯数: 品川区「世帯と人口‐例月表」2026年8月1日現在
- 町丁目境界: 『国勢調査町丁・字等別境界データセット』（CODH作成）「令和2年国勢調査町丁・字等別境界データ」（e-Stat）を加工、CC BY 4.0、doi:10.20676/00000450
- 背景地図: © OpenStreetMap contributors

個人の活動記録、担当者、マンション配布可否はGitHubへ保存されません。

# ポス活ログ

品川区内のポスティング活動を、候補者・選挙ごとの活動アカウントに分けて記録・同期・分析するモバイル向けPWAです。

## 主な機能

- タイマー入力と手動入力
- 複数配布物・複数担当者・町丁目別内訳
- CSVインポート・エクスポート
- 月間目標、活動履歴、分析ダッシュボード
- OpenStreetMapと町丁目別人口・世帯数
- 配布実績による地図表示切り替え
- 大型マンションの配布可否・確認履歴
- LINE等へのテキスト・PNG画像共有
- オフライン入力
- Googleログインによる同一アカウントの複数端末同期
- 候補者・選挙別の活動アカウント作成、切替、名称変更、削除
- デモ（見本データ）アカウントの作成

## デモ（見本データ）

設定・データ管理 →「活動アカウント」→「デモ（見本データ）を作成」で、架空の活動記録が入った活動アカウント `デモ（見本データ）` を作ります。分析ダッシュボードや配布地図の見え方を、実際のデータを入れる前に確認できます。

- 約6か月分の活動記録、3種類の配布物、4人の担当者、月間目標、マンションの配布可否を含みます
- 今使っている活動アカウントのデータは変更しません。不要になったら活動アカウント一覧から削除してください
- 内容は基準日（作成した日）から逆算した架空のものです。実在の配布実績ではありません

Googleログインは利用者本人のデータを分離するために使用します。その内側に複数の活動アカウントを作成でき、活動記録や目標などは互いに混ざりません。

## ローカル起動

```bash
npm run serve
```

`http://localhost:4173/` を開きます。Firebase未設定時は端末内保存モードで動作します。

## Firebase

Firebaseは利用者が手動設定します。詳細は [Firebase手動設定手順](docs/FIREBASE_SETUP.md) を参照してください。

## 検証

```bash
npm test
```

## データ出典

- 人口・世帯数: 品川区「世帯と人口‐例月表」2026年8月1日現在
- 町丁目境界: 『国勢調査町丁・字等別境界データセット』（CODH作成）「令和2年国勢調査町丁・字等別境界データ」（e-Stat）を加工、CC BY 4.0、doi:10.20676/00000450
- 背景地図: © OpenStreetMap contributors

個人の活動記録、担当者、マンション配布可否はGitHubへ保存されません。
